# 第一轮任务提示与开发记录

## 输入依据

用户选定“实验数据体检与可视化工作台”，授权完成作品与材料，指定实际录屏由用户完成，并要求遵循 AI 自己整理的提示。

## 开发任务提示

实现可本地复现的实验表格导入与数据体检。支持 CSV、TSV 和 Excel，保留原始值和稳定行标识。正确处理中文表头、引号、空值、带前导零的样本编号。把缺失值、格式错误、重复行、疑似异常值定位到具体行列，给出可解释的判定依据。所有统计从实际导入的数据计算。

## 验收条件

1. 合成样例和真实上传文件均走同一导入路径。
2. 编号 `001` 保持文本，不变成数字 `1`。
3. 重复行只把额外出现的行计为可删除重复，保留首次记录。
4. 数值格式错误与空值分别统计。
5. 原始数据在问题定位和筛选过程中保持可追溯。

## 实现与验证

已实现独立的 TypeScript 数据模型、数值/日期解析、稳定行标识、类型识别、四类问题定位、数值统计和 CSV 导出。CSV/TSV/XLSX 浏览器导入适配器已写入，浏览器入口的实际文件导入仍待下一步验证。
