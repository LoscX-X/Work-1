# 第三轮任务提示与开发记录

## 开发任务提示

把已经实现的导入、检查和清洗连接成可解释的分析交付。图表必须基于当前真实数据计算，显示参与分析和排除记录的数量。保留填充和人工修改的来源，支持回到原始记录。导出的操作配置包含源文件指纹、版本和参数，可以在同一原始文件上原子回放，并核对最终结果指纹。报告和 CSV 必须与当前界面结果一致。

## 验收条件

1. 散点、趋势和直方图可切换字段，统计和拟合来源可核对。
2. 数值运算覆盖常量列、无有效观测及大数值等可实际输入的边界。
3. 填充值单独标识，分析可以明确排除这些替代值。
4. 点击原始/当前图表中的点能定位到相应版本的源记录。
5. 配置只保存当前已生效的操作序列，回放失败不会留下部分状态。
6. 错误原文件、错误工作表、未知操作和不支持版本给出明确提示。
7. CSV、JSON 处理记录和自包含 HTML 报告的行数与参数可交叉验证。

## 实现与验证

本轮由用户全权委托后，AI 根据已确认范围拆出以上实现任务；它们是实际使用的开发任务说明，不冒充用户逐条输入的聊天。

- 分离图表点集收集、ECharts 配置、统计摘要、填充来源、清洗配置、报告构建与导出 hooks，界面继续围绕既定实验数据流程。
- 配置保存当前生效操作前缀、源文件 SHA-256、工作表和最终数据指纹；回放在独立历史中完成，全部校验通过后才允许确认替换。异步导入/回放通过版本检查避免过期任务覆盖新的工作区。
- 数值边界回归先暴露了 `1e308` 均值溢出；改用缩放运算后，有限大数的均值、分位数、回归与分箱测试通过。重复表头与既有 `_2` 后缀发生重名、年份 0000 的闰日被错误拒绝也先由测试复现，再分别修复唯一命名和日历校验。
- Excel 编号列的简单零掩码保留前导零；测量列保留底层完整精度。真实导入 `formatting-cases.xlsx` 后，界面显示 3 条记录、编号 `001` 和读数 `1.234567`，换文件后的图表/问题计数也随之改变。
