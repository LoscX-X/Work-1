# 第二轮任务提示与开发记录

## 开发任务提示

在第一轮真实导入与体检基础上，实现可预览、可撤销、可重做的清洗工作流。每个操作必须是从输入数据和明确参数计算结果的纯函数。记录变更单元格、删除记录及处理前后的质量检查。用户确认预览后才提交操作。保留原始值和源记录序号，支持按相同参数重新执行。

## 验收条件

1. 预览不会修改原始数据或当前结果。
2. 删除重复保留首次记录，删除异常值必须显式确认。
3. 平均数/中位数填充只适用于数值列；全为空的数值列给出可解释错误。
4. 撤销/重做恢复精确状态，新分支使旧重做分支失效。
5. 手动修正单元格和列类型也进入操作历史。
6. 相同原文件与同一操作序列能够得到完全一致的数据结果。

## 实现与验证

已按职责实现操作类型、逐格处理、整行处理、操作应用器、历史状态、导入状态、通知状态，以及独立的参数表单、影响预览、操作列表和单元格修正对话框。

新增用例覆盖输入不变性、精确变更记录、中位数填充、无有效数值错误、非法常量、撤销/重做、新分支失效、空结果和无变更操作不产生历史。

实际浏览器验证如下。

- 从真实 CSV 示例进入“清洗工作流”，初始 163 行、13 个检查项、0 步历史。

- 取消预览后仍是 163 行、13 个检查项、0 步历史。
- 确认执行后是 160 行、10 个检查项、1 步历史。
- 撤销后回到 163 行与13个检查项，重做后再次回到160行。

该轮确认了真实入口的取消预览、去重、撤销、重做和数值填充。其它操作由算法用例和类型检查覆盖，完整回放/图表/导出尚待下一轮验证。
