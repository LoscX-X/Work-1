# 第五轮任务提示与界面复验

用户要求界面更清晰，减少装饰感，并准备可以照着操作的录屏步骤。

## 开发任务提示

优先处理录屏中看不清的表头、行号、图表坐标与清洗变更。概览显示简明的行列数、待核对问题和参考分，精简重复说明。统一主操作颜色并保留问题类型的文字。沿用现有导入、定位、清洗、分析与回放流程。录屏用同一份传感器样例串联这些操作。

## 验收条件

1. 从真实页面检查概览、问题筛选、清洗预览与图表，确认字段、单位、数值和按钮可读。
2. 核对同一份样例载入后的 163 行和 13 个检查项，七步配置回放后的 150 行和 0 个检查项。
3. 录屏指南、预构建包和技术文档使用同一版本，讲稿按当前页面的实际操作编排。

## 实际结果

- 概览使用并排数值和直接可点的问题列表。表头、行号、变更预览和图表文字加大并加深，主要操作使用统一的蓝色。
- Node.js 22.19.0 下通过类型检查、25 项测试、生产构建及格式检查。既有两份浏览器导出作为 v1.0.0 的实际结果保存。
- 用本次构建所带 CSV 和配置调用导入、检查、配置回放和分析函数，得到 163 行 / 6 列 / 13 项，七步回放后为 150 行 / 0 项，拟合 R² 为 0.9998177010425915。检查在 Node.js 中执行。
- 内置浏览器的访问设置拦截了 v1.0.1 开发地址，因此新界面尚未实际复看。录屏指南给出示例载入和试录检查点。
